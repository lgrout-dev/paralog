Légende :
  Pool vide  : créer N workers, leur donner une tâche vide, les arrêter (coût fixe)
  phase par. : Pool + analyse des blocs + renvoi des résultats ; worker max = bloc le plus long
  surcoût    : phase par. - worker max (démarrage, envoi, pickle des résultats, arrêt)
  CPU total  : somme des temps de calcul des workers (augmente si les cœurs sont partagés)
  renvoyé    : taille des résultats sérialisés (pickle) recopiés vers le principal
  non par.   : (découpage + surcoût + fusion) / total
